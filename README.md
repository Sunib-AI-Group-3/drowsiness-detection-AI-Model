## 🛠️ Cara Kerja Tim (3 Langkah Gampang)
> Biar kode nggak tabrakan (*conflict*) dan progress terpantau rapi, ikuti 3 aturan simpel ini:

1. **Ambil Tugas di Board:**
   * Klik [**Buka Kanban Board**](https://github.com/orgs/Sunib-AI-Group-3/projects/1) di atas.
   * Pilih kartu tugas di kolom **`Ready`**, geser ke **`In progress`**, lalu klik kartunya dan *assign* nama kalian.
2. **Ngoding di Branch Sendiri (Jangan langsung ke `main`!):**
   * Buat *branch* baru di laptop kalian sesuai tugasnya:
     ```bash
     git checkout -b feat/nama-fitur
     # Contoh: git checkout -b feat/dataset-preprocessing
     ```
3. **Upload & Buat Pull Request (PR):**
   * Setelah selesai ngoding atau eksperimen model:
     ```bash
     git add .
     git commit -m "feat: selesai membuat preprocessing dataset (#NOMOR_ISSUE)"
     git push origin feat/nama-fitur
     ```
   * Buka tab **Pull Requests** di GitHub, klik **New pull request**, lalu *merge* ke `main` setelah dicek teman setim.
